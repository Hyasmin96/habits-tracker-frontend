## Habits Tracker Frontend

Frontend del Habits Tracker desarrollado con **Next.js** y **Redux**.


## Instalación

```bash
npm install
npm run dev
```


## Uso

- Abre http://localhost:3000 en tu navegador.
- La página muestra tus hábitos cargados desde el backend.


## Tecnologías

- Next.js
- React
- Redux Toolkit
- TypeScript
